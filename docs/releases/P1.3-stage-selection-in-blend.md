# P1.3 배합 화면 성장단계 선택 프로토타입 릴리즈 노트

## 1. 이번 단계 이름

- `P1.3 배합 화면 성장단계 선택`

## 2. 이번 단계 목적

- 배합 화면에서 사용자가 직접 `육성기 / 비육전기 / 비육후기`를 선택하게 해서, 분석 기준을 배합 편집 단계에서 바로 바꿀 수 있게 한다.

## 3. 포함 기능 목록

- 배합 화면에 `성장 단계 선택` 섹션 추가
- `육성기 / 비육전기 / 비육후기` segmented picker 추가
- 단계 변경 시 결과 화면 기준과 판정이 해당 단계에 맞게 반영
- 선택한 단계의 요약 설명 노출
- Xcode 시뮬레이터 빌드 검증

## 4. 제외 기능 목록

- 단계별 여러 배합 비교 화면
- 성장단계 자동 추천
- 단계별 저장 이력

## 5. 우선 확인할 포인트

- 배합비 선택 바로 아래에 단계 선택이 있는 구조가 자연스러운지
- 단계 변경 후 바로 `분석 결과 보기`로 이어지는 흐름이 맞는지
- 단계 설명 문구가 충분한지

## 6. 다음 단계 후보

- 단계별 배합 템플릿 시작값 제공
- 최근 분석 목록에 단계 변경 이력 반영
- 결과 화면에서 단계 변경 바로가기 추가
