# M1.6.2 성장단계 기준 범위/주의 밴드 반영

## 이번 단계 목적

성장단계별 목표 영양성분 기준을 `최소치 중심`에서 `권장 범위 + 주의 밴드` 구조로 바꿨습니다.  
이번 반영부터 분석 화면은 `적정 / 주의 / 부족 / 과잉` 기준으로 판정합니다.

## 반영 내용

### 1. StageCriteria 구조 확장

기존:

- `CP 최소`
- `TDN 최소`
- `NDF/ADF 범위`
- `EE 상한`
- `Ca:P 비율 범위`

변경 후:

- `CP 권장 범위 + 주의 하한/상한`
- `TDN 권장 범위 + 주의 하한/상한`
- `NDF 권장 범위 + 주의 하한/상한`
- `ADF 권장 범위 + 주의 하한/상한`
- `Ca 절대량 범위 + 주의 하한/상한`
- `P 절대량 범위 + 주의 하한/상한`
- `Ca:P 비율 범위 + 주의 하한/상한`
- `EE 상한 + 주의 상한`
- `수분 권장 범위 + 주의 하한/상한 + 하드 상한`

### 2. 성장단계별 기준

#### 육성기

- `CP`: 적정 `14~18`, 주의 `12.5~14 / 18~20`
- `TDN`: 적정 `68~75`, 주의 `65~68 / 75~78`
- `NDF`: 적정 `35~45`, 주의 `31~35 / 45~50`
- `ADF`: 적정 `20~28`, 주의 `18~20 / 28~31`
- `Ca`: 적정 `0.45~0.80`, 주의 `0.38~0.45 / 0.80~0.90`
- `P`: 적정 `0.28~0.45`, 주의 `0.24~0.28 / 0.45~0.52`
- `Ca:P`: 적정 `1.5~2.0`, 주의 `1.3~1.5 / 2.0~2.3`
- `EE`: 적정 `<= 6.0`, 주의 `6.0~6.6`
- `수분`: 적정 `40~45`, 주의 `35~40 / 45~50`, 부족 `<35`, 과잉 `>50`, 하드 상한 `60`

#### 비육전기

- `CP`: 적정 `12~15`, 주의 `11~12 / 15~17`
- `TDN`: 적정 `72~76`, 주의 `69~72 / 76~79`
- `NDF`: 적정 `30~38`, 주의 `27~30 / 38~42`
- `ADF`: 적정 `18~24`, 주의 `16~18 / 24~27`
- `Ca`: 적정 `0.35~0.65`, 주의 `0.30~0.35 / 0.65~0.75`
- `P`: 적정 `0.22~0.38`, 주의 `0.19~0.22 / 0.38~0.44`
- `Ca:P`: 적정 `1.5~2.0`, 주의 `1.3~1.5 / 2.0~2.3`
- `EE`: 적정 `<= 6.0`, 주의 `6.0~6.6`
- `수분`: 적정 `40~45`, 주의 `35~40 / 45~50`, 부족 `<35`, 과잉 `>50`, 하드 상한 `60`

#### 비육후기

- `CP`: 적정 `11~13`, 주의 `10~11 / 13~14`
- `TDN`: 적정 `73~78`, 주의 `70~73 / 78~81`
- `NDF`: 적정 `25~32`, 주의 `22~25 / 32~36`
- `ADF`: 적정 `15~20`, 주의 `13~15 / 20~23`
- `Ca`: 적정 `0.30~0.60`, 주의 `0.25~0.30 / 0.60~0.70`
- `P`: 적정 `0.20~0.35`, 주의 `0.17~0.20 / 0.35~0.41`
- `Ca:P`: 적정 `1.5~2.0`, 주의 `1.3~1.5 / 2.0~2.3`
- `EE`: 적정 `<= 6.0`, 주의 `6.0~6.6`
- `수분`: 적정 `40~45`, 주의 `35~40 / 45~50`, 부족 `<35`, 과잉 `>50`, 하드 상한 `60`

### 3. 상태 판정 변경

분석 화면 판정 기준:

- `적정`: 권장 범위 안
- `주의`: 권장 범위 밖이지만 주의 밴드 안
- `부족`: 주의 하한보다 낮음
- `과잉`: 주의 상한보다 높음

적용 대상:

- `CP`
- `TDN`
- `NDF`
- `ADF`
- `Ca`
- `P`
- `Ca:P`
- `EE`
- `수분`

### 4. 엔진 핵심 목표 충족 기준 변경

`isFullyResolved`와 `allCoreTargetsSatisfied`는 이제 아래를 모두 만족해야 `true`입니다.

- `CP` 권장 범위
- `TDN` 권장 범위
- `EE <= 6.0`
- `Ca` 권장 범위
- `P` 권장 범위
- `NDF` 권장 범위
- `ADF` 권장 범위
- `Ca:P` 권장 범위
- `수분 40~45`

### 5. 해결률 계산 범위 확장

`resolutionRate` 계산은 이제 아래 항목의 이탈 거리 개선을 반영합니다.

- `CP`
- `TDN`
- `EE`
- `NDF`
- `ADF`
- `Ca`
- `P`
- `Ca:P`
- `수분`

## 확인 포인트

- 같은 배합이라도 성장단계가 바뀌면 `CP`, `TDN`, `Ca`, `P` 판정이 달라지는지
- `주의`와 `부족/과잉`이 기존보다 더 세밀하게 구분되는지
- `Ca`와 `P`가 적정이어도 `Ca:P`가 벗어나면 따로 표시되는지
- `수분 35~40% / 45~50%` 구간이 `주의`, `<35%`가 `부족`, `>50%`가 `과잉`으로 보이는지
