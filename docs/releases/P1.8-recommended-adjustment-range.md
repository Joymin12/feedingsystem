# P1.8 권장 보강량 표시 프로토타입 릴리즈 노트

## 1. 이번 단계 이름

- `P1.8 권장 보강량 표시`

## 2. 이번 단계 목적

- 추천 원료만 보여주는 수준에서 멈추지 않고, 사용자에게 대략 어느 정도 보강해야 하는지 함께 보여준다.
- 보강량은 정답값이 아니라 `검토 범위`로 제시한다.

## 3. 포함 기능 목록

- `AI 추천` 화면에 `권장 보강량` 추가
- CP 부족 시 단백질원 후보별 보강 범위 계산
- TDN 부족 시 에너지원 후보별 보강 범위 계산
- 보강량 계산이 부적절한 항목은 숫자 대신 설명형 문구 표시
  - 예: `현 상태 유지`
  - 예: `비율 점검 우선`
  - 예: `권장 보강량 계산 불가`

## 4. 제외 기능 목록

- 실제 최적화 기반 정밀 보강량 계산
- 다원료 동시 조정 시뮬레이션
- 수분/NDF/Ca:P 제약을 반영한 동적 상한 재계산 고도화

## 5. 우선 확인할 포인트

- `권장 보강량`이 숫자 한 개보다 범위로 보이는 것이 더 자연스러운지
- 유지/점검 중심 추천에는 숫자 대신 설명이 나오는 것이 맞는지
- CP/TDN 부족 상황에서 제시되는 kg 범위가 과하게 보이지 않는지

## 6. 다음 단계 후보

- 보강량 계산 시 수분/NDF/Ca:P 제약을 더 직접 반영
- 추천별 조정 후 예상 변화량 표시
- 실제 원료 DB 기준으로 범위 재보정
