# M1.9.8 source extension 220s and developer brief

## 반영 내용

- `ingredients.source.extensions.final.json`을 기존 `115~130` 임시 세트에서 `210~233` 최종 세트로 교체
- `217 커피박`, `221 옥수수` 제외 반영
- `IngredientCatalog.swift`에 `FEED_210~233` 중 운영 포함 22개 편입
- 결측 영양값은 app catalog에서 `0`으로 편입
- 현재 정책상 이 원료들도 추천 후보군에 포함
- 개발자용 설명 문서 추가
  - `docs/tmr-recommendation-engine-developer-brief.md`

## 주의

- source DB는 `null`을 유지한다.
- app catalog는 현재 모델 제약상 `null`을 허용하지 않으므로 결측값을 `0`으로 편입한다.
- 이 정책은 입력 가능성과 구현 속도를 우선한 것이며, 추천 정확도 리스크가 있다.

## 다음 작업

- 결측값을 optional로 다룰 수 있는 nutrition 모델 리팩토링 검토
- `CUSTOM_SOYBEAN_MEAL`과 `FEED_232 대두박`의 canonical 정리
- 추천 후보 품질 점검용 회귀 테스트 재실행
