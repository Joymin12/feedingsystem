# P1.5 분석 결과 화면 구조 정리 프로토타입 릴리즈 노트

## 1. 이번 단계 이름

- `P1.5 분석 결과 화면 구조 정리`

## 2. 이번 단계 목적

- 분석 결과 화면의 정보 구조를 더 자연스럽게 정리한다.
- 상단 과한 카드 느낌을 줄이고, `성분 예상치 -> 현재 단계 기준 -> 판정 결과 -> AI 추천` 흐름으로 읽히게 만든다.

## 3. 포함 기능 목록

- 상단 큰 요약 카드를 간소화한 헤더로 변경
- `배합 요약` 명칭을 `성분 예상치`로 변경
- `현재 단계 기준` 카드 내부 정렬 정리
- 섹션 점프 버튼 추가
  - 성분 예상치
  - 현재 단계 기준
  - 판정 결과
  - AI 추천
- `다음: 판정 결과 보기`
- `다음: AI 추천 보기`
- Xcode 시뮬레이터 빌드 검증

## 4. 제외 기능 목록

- 결과 화면 접기/펼치기
- 단계 기준 고정 상단 바
- 실제 네비게이션 탭 분리

## 5. 우선 확인할 포인트

- `성분 예상치`라는 이름이 자연스러운지
- `현재 단계 기준` 카드가 덜 붕 뜨는지
- `판정 결과`로 내려가는 흐름이 자연스러운지
- 상단 점프 버튼이 실제로 도움이 되는지

## 6. 다음 단계 후보

- 결과 화면 섹션 축약/펼침
- 판정 결과 중요도 정렬
- 추천 결과에 실제 조정안 수치 표시
