# M1.2 배합 교정 엔진 1차 릴리즈 노트

## 단계 이름
`M1.2 배합 교정 엔진 1차`

## 목적
단일 원료 추가 추천(M1.1)에서 한 단계 나아가, **문제 원료 감량 + 부족분 보완**이 묶인 배합 교정안을 생성합니다.
사용자는 "대두박 추가"가 아니라 "미강 -15kg, 옥수수 +8kg, 대두박 +2kg" 형태의 교정안을 봅니다.

---

## 포함 기능

### 1. EE(조지방) 기준 추가
- `StageCriteria`에 `eeMaxPctDm` 필드 추가 (전 단계 공통 6%)
- 분석 결과 상태 카드에 `EE` 항목 추가

### 2. 교정 데이터 구조 추가
- `CorrectionActionType`: `decrease | increase | add`
- `CorrectionAction`: 원료 ID, 원료명, 타입, 양, 표시 문구
- `EECorrectionContext`: 감량 대상 원료, 감량 후 배합, 감량 후 성분, 비용 변화
- `Recommendation.correctionActions: [CorrectionAction]`: 교정 액션 목록 추가

### 3. EE 과다 교정 흐름
- EE가 기준 초과 시 현재 배합에서 EE 기여도 1위 원료를 감량 타깃으로 선정
- **이진 탐색(14회)** 으로 EE를 기준 이하로 낮추는 최소 감량량 계산 (임의 -5/-10/-20kg 단계 제거)
- 감량 후 배합(`reducedFormula`)을 기반으로 CP/TDN 보완 원료 추천 연결
- 최종 `correctionActions` = `[감량 액션] + [보완 증량 액션]`

### 4. `simulateApplying(actions:to:)` 추가
- 복수 `CorrectionAction`을 순서대로 배합에 적용
- decrease 시 `max(0, 현재량 - 감량)` 처리 (음수 방지)
- 적용 후 `calculateMetrics` 재계산

### 5. simulatedMetrics 정확도 수정 (버그 수정)
- 기존: `trialAmountKg`(시뮬레이션 기준량) 기반 성분 표시
- 수정: 실제 `increaseAction.amountKg`(권장 보강량)을 적용한 성분으로 재계산
- "현재 → 적용 후" 비교가 실제 교정안과 일치

### 6. primaryClosureSum 가중치 수정 (버그 수정)
- 기존: `cpClosure + tdnClosure` (CP/TDN 결핍 크기 무관하게 동등 합산)
- 문제: CP -5%p, TDN -0.5%p 상황에서 TDN만 해결하는 후보가 상위에 오는 현상
- 수정: 결핍 크기 비례 가중합 `(cpNeed/totalDeficit) * cpClosure + (tdnNeed/totalDeficit) * tdnClosure`
- 더 큰 결핍을 해결하는 원료가 올바르게 상위에 위치

## 제외 기능
- NDF/ADF/Ca:P 과잉 교정 (다음 단계)
- 다중 과잉 성분 동시 교정
- 기존 원료 교체 중심 전략
- 실제 AI 설명 API 연동
- 서버 저장/동기화

---

## 확인 포인트
- EE가 기준 초과인 배합에서 감량 액션이 교정안 앞에 표시되는지
- 감량 후 CP/TDN 보완 원료가 함께 제시되는지
- "현재 → 적용 후" 성분 비교가 실제 교정 액션량과 일치하는지
- CP/TDN 동시 부족 시 더 큰 결핍 해결 원료가 상위에 오는지
- 같은 배합 입력에서 항상 같은 교정안이 생성되는지
