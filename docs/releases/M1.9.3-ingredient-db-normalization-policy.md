# M1.9.3 원료 DB 정규화 정책 고정

## Summary

원료 DB 최종 반영 전에 raw 원료 데이터의 정규화 정책을 고정했다.
이번 단계는 `130건 원본 -> 최종 DB` 반영 기준을 문서와 정책 파일로 먼저 확정하는 작업이다.

## Policy

- 결측 영양성분은 `0`으로 치환하지 않고 `null` 유지
- 아래 6개 원료는 중복 제거하지 않고 독립 원료로 유지
  - `118 맥강`
  - `125 비지`
  - `126 미강`
  - `128 루핀`
  - `130 감귤박`
  - `122 주정박`
- 아래 원료는 최종 DB에서 제외
  - `21 커피피`
  - `50 커피부산물`
  - `94 화분(꽃가루)`
  - `95~107` 동물성/곤충류/낙농가공부산물
  - `108 산화아연`
  - `119 커피박`
- 카테고리 override
  - `34 장유박 -> 농후사료`
  - `121 참깻묵(호마박) -> 농후사료`
  - `123 소맥피(밀기울) -> 농후사료`
