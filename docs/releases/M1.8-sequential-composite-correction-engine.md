# M1.8 순차 복합 교정 엔진

## 이번 단계 목적

기존 교정 엔진은 `EE / NDF / ADF` 과잉만 감량 대상으로 보고,  
`CP / TDN`은 부족할 때만 보강 후보를 찾는 구조였습니다.

이번 반영부터는:

- `CP 과잉`
- `TDN 과잉`

도 실제 감량 대상으로 포함하고,

`과잉 감량 -> 전체 재계산 -> 부족 보완`

을 순차적으로 수행하는 복합 교정 엔진으로 확장했습니다.

## 반영 내용

### 1. 과잉 감지 대상 확장

기존:

- `EE`
- `NDF`
- `ADF`

변경 후:

- `CP`
- `TDN`
- `EE`
- `NDF`
- `ADF`

즉 `CP`와 `TDN`도 기준 상한을 넘으면 감량 교정 후보로 들어갑니다.

### 2. 과잉 우선순위 도입

과잉 후보가 여러 개일 때는 아래 순서로 우선 처리합니다.

- `CP`
- `TDN`
- `EE`
- `NDF`
- `ADF`

동일 우선순위 안에서는 초과폭이 큰 항목을 먼저 선택합니다.

### 3. 감량 타깃 원료 선택 방식 변경

과잉 성분이 발생하면 해당 성분에 가장 많이 기여하는 원료부터 감량 후보로 검토합니다.

예:

- `CP 과잉` -> 단백질 기여도 높은 원료
- `TDN 과잉` -> 에너지 기여도 높은 원료
- `EE 과잉` -> 지방 기여도 높은 원료

단, 감량 시 다른 핵심 성분이 즉시 하한 아래로 떨어지면 해당 후보는 제외하고 다음 기여 원료를 검토합니다.

### 4. 감량량 계산 규칙 추가

감량량은 고정값이 아니라 계산으로 정합니다.

규칙:

1. 우선 목표치까지 감량되는 양을 역산
2. 역산이 불안정하거나 과도하면 fallback 적용

fallback 순서:

- 역산 감량량
- 현재 투입량의 `50%`
- 현재 투입량의 `25%`

추가 안전장치:

- `CP`, `TDN`은 상한선 바로 맞춤이 아니라 `상한 - 0.5%p`를 목표로 감량
- 감량 후 해당 원료는 최소 `1kg` 이상 남김

### 5. 감량 후 전체 재계산 강화

감량 액션을 하나 적용할 때마다:

- 전체 배합 재계산
- 남은 과잉 확인
- 새로 생긴 부족 확인

을 다시 수행합니다.

즉 부분 계산이 아니라 항상 전체 배합 기준으로 다시 판단합니다.

### 6. 반복 제한 추가

순차 교정 루프는 최대 `3회`까지만 수행합니다.

이유:

- 무한 루프 방지
- `감량 -> 보완 -> 재과잉` 반복 억제

3회 안에 정리되지 않으면 현재 단계 자동 교정 한계를 넘는 것으로 보고 상위 로직에서 `재설계 검토` 쪽으로 떨어질 수 있게 했습니다.

### 7. 교정 설명문 톤 통일

교정 엔진 설명도 분석 화면과 같은 톤으로 맞췄습니다.

기준:

- `주의`: `권장합니다`, `고려해보세요`
- `부족/과잉`: `점검이 필요합니다`

예:

- `Ca:P 비율은 함께 점검을 권장합니다.`
- `신규 원료 추가를 고려해보세요.`
- `비용 증가는 함께 검토를 권장합니다.`

### 8. 과잉 교정 설명 강화

과잉 교정이 먼저 들어간 추천안은 이유 문구 앞에 감량 설명을 붙입니다.

예:

- `CP 수준이 높아 대두박 약 4.0kg 감량을 먼저 적용했습니다.`
- `조지방(EE) 수준이 높아 미강 약 6.0kg 감량을 먼저 적용했습니다.`
