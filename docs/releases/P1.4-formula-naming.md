# P1.4 배합 이름 입력 프로토타입 릴리즈 노트

## 1. 이번 단계 이름

- `P1.4 배합 이름 입력`

## 2. 이번 단계 목적

- 샘플용 `A/B` 이름을 제거하고, 사용자가 배합 화면에서 직접 `배합 이름`을 입력할 수 있게 한다.
- 배합 관련 용어를 더 자연스럽게 정리한다.

## 3. 포함 기능 목록

- 샘플 배합 이름 변경
  - `비육전기 기본 배합`
  - `육성기 기본 배합`
- `배합비 선택` 용어를 `배합 선택`으로 변경
- 배합 화면에 `배합 이름` 입력 필드 추가
- 입력한 배합 이름이 분석 결과, 최근 분석, 내 농장 등 기존 화면에 그대로 반영
- Xcode 시뮬레이터 빌드 검증

## 4. 제외 기능 목록

- 배합 복제
- 배합 삭제
- 배합 이름 자동 추천

## 5. 우선 확인할 포인트

- `배합 이름`이라는 용어가 자연스러운지
- 배합 선택과 이름 입력 위치가 헷갈리지 않는지
- 이름을 바꾼 뒤 다른 화면에도 즉시 반영되는지

## 6. 다음 단계 후보

- 배합 생성/삭제 기능 추가
- 분석 결과 화면에서 이름 바로 수정
- 최근 분석에서 배합명 검색
