# M1.6 부족/복합 교정 엔진

## 이번 단계 목적

과잉 성분만 단독으로 다루던 교정 엔진을 `과잉 먼저 -> 부족 보완` 흐름으로 확장했습니다.  
이번 릴리즈의 목표는 Swift 시뮬레이터에서 같은 입력에 대해 항상 같은 교정안이 나오도록 결정론적 규칙을 강화하는 것입니다.

## 포함 기능

- `EE / NDF / ADF` 과잉을 한 번만 보지 않고 최대 10회까지 순차 교정
- 과잉 교정 후 남은 `CP / TDN` 부족을 기준으로 추천안 생성
- 추천안별 최종 적용 성분을 `감량 액션 + 증량 액션` 전체로 다시 계산
- 추천안에 `resolutionRate`, `isFullyResolved` 메타데이터 추가
- 다중 과잉 교정 시 이유 문구에 감량 원료/감량 이유를 함께 반영

## 구현 핵심

### 1. 과잉 교정 베이스

신규 `CorrectionBase`를 추가했습니다.

- 누적 감량 액션 목록
- 감량 후 중간 배합
- 감량 후 성분
- 누적 비용 변화
- 교정한 영양소 이름
- 교정한 원료 이름

`buildRecommendations()`는 이제 먼저 `applyOverageCorrections()`를 호출해 과잉을 순차적으로 줄인 뒤, 그 결과를 기준으로 부족 보완 추천안을 만듭니다.

### 2. 순차 과잉 교정

- 매 반복마다 `EE / NDF / ADF` 중 초과폭이 가장 큰 성분을 선택
- 해당 성분 기여도가 가장 큰 원료를 감량 대상으로 삼음
- 감량 후 전체 재계산
- 더 이상 과잉이 없거나 같은 액션이 반복되면 중단
- 최대 반복 횟수는 10회

### 3. 최종 예상 성분 재계산

기존에는 trial amount 기준 시뮬레이션 결과를 그대로 보여주는 경우가 있었지만,  
지금은 실제 추천 카드에 들어간 `correctionActions` 전체를 다시 적용해서 `현재 -> 적용 후 예상`을 계산합니다.

### 4. 해결률 메타데이터

추천안마다 아래 값을 계산합니다.

- `resolutionRate`
  - 현재 위반된 각 문제의 개선률 중 최저값
- `isFullyResolved`
  - 최종 성분이 핵심 기준을 모두 만족하는지 여부

대상 문제:

- `CP 부족`
- `TDN 부족`
- `EE 과다`
- `NDF 범위 이탈`
- `ADF 범위 이탈`
- `Ca:P 범위 이탈`
