## Summary

출시 전 엔진 검증에 필요한 회귀 테스트 배합 세트를 앱에 고정하고, 원료 DB 파일 역할을 문서로 분리했다.

## Added Test Formulas

- `엔진검증 - CP 과잉`
  - 기대 방향: 단백질원 감량 우선
- `엔진검증 - TDN 과잉`
  - 기대 방향: 고에너지 곡류/당밀 감량 우선
- `엔진검증 - CP 부족`
  - 기대 방향: 단백질원 보강 우선
- `엔진검증 - EE 과잉 + CP 부족`
  - 기대 방향: 고지방 원료 감량 후 단백질원 보강
- 기존 유지
  - `경기TMR 3000kg 테스트 배합`
  - `비육전기 기본 배합`
  - `육성기 기본 배합`
