# P1.11 영양소 화면 원물/건물 이중 구조 릴리즈 노트

## 1. 이번 단계 이름

- `P1.11 영양소 화면 원물/건물 이중 구조`

## 2. 이번 단계 목적

- 분석 결과 화면을 설명서 기준에 맞게 재구성한다.
- 원물 투입 현황(원료별 원물량 + 건물 환산량)을 테이블로 명확히 보여준다.
- 건물 기준 영양소 섹션을 별도로 분리해 정보 계층을 명확하게 한다.

## 3. 포함 기능 목록

### AnalysisDetailView 개편
- **원물 투입 현황** 섹션 추가: 원료별 행(원료명 | 원물량 | 건물량) + 합계 행
  - DB 등록 원료: 건물량 = 원물량 × (dmPct / 100)
  - 직접 입력 원료: 건물량 "—" 표시 (성분 DB 없음)
- **건물 기준 영양소** 섹션으로 분리: 기존 영양소 그리드 유지
- 기존 MetricTile 2개(총 원물량, 총 건물량) 제거 → 원물 투입 현황 합계 행으로 통합
- 원료 한 줄 나열 텍스트 제거 → 테이블로 대체

## 4. 제외 기능 목록

- 수분 조정 (영양소는 DB 고정)
- 원료별 성분 개별 표시 (복잡도 우선순위 낮음)
- 목표 섭취량(두수 × 1두 급여량) 입력 기반 총 필요량 계산

## 5. 우선 확인할 포인트

- 원료별 건물량이 올바르게 계산되는지 (원물량 × DM%)
- 직접 입력 원료(definitionID 없음)에서 건물량 "—" 표시 확인
- 합계 행(총 원물량, 총 건물량)이 기존 MetricTile 값과 일치하는지
