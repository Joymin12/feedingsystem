# P1.7 홈 화면 진입 구조 단순화 프로토타입 릴리즈 노트

## 1. 이번 단계 이름

- `P1.7 홈 화면 진입 구조 단순화`

## 2. 이번 단계 목적

- 홈 화면에서 의미가 약한 `대표 분석 보기`를 제거한다.
- 사용자가 바로 이해할 수 있는 3개의 핵심 진입점만 남긴다.

## 3. 포함 기능 목록

- 홈 화면 빠른 진입 카드 정리
  - `배합하기`
  - `최근 분석`
  - `사육일지`
- `대표 분석 보기` 제거
- 홈 화면의 별도 최근 분석 미리보기 섹션 제거

## 4. 제외 기능 목록

- 대표 배합 고정 기능
- 홈 화면 추천 카드
- 최근 분석 즐겨찾기

## 5. 우선 확인할 포인트

- `배합하기 / 최근 분석 / 사육일지` 3개가 메인 진입점으로 충분한지
- 홈 화면이 이전보다 덜 헷갈리는지
- `최근 분석`과 `사육일지` 구분이 사용자 입장에서 자연스러운지

## 6. 다음 단계 후보

- 홈 화면 카드 순서 조정
- 최근 분석 검색/필터
- 배합 생성과 저장 흐름 단순화
