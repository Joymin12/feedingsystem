# P0 화면/흐름 고정 릴리즈 노트

## 1. 이번 단계 이름

- `P0 화면/흐름 고정`

## 2. 이번 단계 목적

- 피그마에서 앱의 기본 사용자 흐름을 확정한다.
- 사용자가 배합 분석과 사육일지 흐름을 이해하고 직접 눌러볼 수 있게 한다.

## 3. 포함 기능 목록

- 회원가입 / 로그인
- 첫 가입 시 사육 단계 선택
- 홈
- 배합 입력
- 분석 결과
- 최근 분석
- 사육일지 목록
- 기록 추가
- 기록 상세 / 기록 수정
- 내 농장
- 커뮤니티 기본 화면

## 4. 제외 기능 목록

- 실제 API 연동
- 실제 AI 추천 호출
- 실제 저장소 동기화
- 커뮤니티 상세, 글쓰기

## 5. 우선 확인할 포인트

- 배합 입력이 직관적인지
- 분석 결과에서 부족/과잉을 이해할 수 있는지
- 사육일지에서 `기록 추가 -> 배합비 선택 -> 글쓰기 -> 기록 수정` 흐름이 자연스러운지
- 하단 탭 구조가 과하지 않은지
