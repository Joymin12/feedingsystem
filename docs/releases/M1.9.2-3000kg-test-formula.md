# M1.9.2 3000kg 테스트 배합 추가

## Summary

사용자 제공 `3000kg` 배합을 앱 내부 공식 테스트 케이스로 추가했다.
이 배합은 복합교정안 엔진 검증용 기준 케이스로 사용한다.

## Mapping Assumptions

카탈로그에 정확한 1:1 항목이 없는 원료는 아래 기준으로 매핑했다.

- `버섯배지` → `버섯재배부산물(느타리)`
- `깻묵` → `들깻묵(임자박)`
- `미강` → `쌀겨(생미강)`
- `볏짚` → `볏짚(사일리지)`

추가 항목:

- `대두박`
  - 시드 기준 영양값으로 카탈로그에 신규 추가
- `이스트컬쳐`
  - 영양 기여 `0`의 placeholder 보충제 항목으로 신규 추가
  - 추천 후보군에서는 제외

## Purpose

이 테스트 배합은 아래를 검증하기 위한 기준 케이스다.

- `Ca:P` 불균형 탐지
- `P` 과다 가능성 확인
- 비육전기 기준 `TDN` 부족/주의 판정
- 복합교정안이 `감량 + 증량 + 조사료 대체` 방향으로 발전할 필요성 확인

## Expected Baseline Analysis

현재 기준과 매핑 전제를 적용하면 이 배합은 아래 방향으로 해석되는 것이 맞다.

- `수분`
  - `볏짚(사일리지)` 전제에서는 `35~40%` 구간의 `주의` 가능성이 높다.
- `CP`
  - 비육전기 기준에서는 대체로 `적정` 또는 상단 근처로 해석될 수 있다.
- `TDN`
  - 비육전기 기준 `72~76%`와 비교하면 `부족` 또는 `주의(부족)` 가능성이 있다.
- `Ca`
  - 절대량은 크게 부족하지 않을 수 있으나, `P`와 함께 봐야 한다.
- `P`
  - `미강`, `깻묵`, `맥강` 기여로 높게 나올 가능성이 있다.
- `Ca:P`
  - 가장 핵심적인 문제 후보다. 비율이 `1.5~2.0`보다 낮게 계산되면 우선 교정 대상이다.

즉 이 케이스는 단순 단일 원료 추천보다 아래 방향의 복합교정안이 나오는지 보는 테스트 케이스다.

- `P` 기여 원료 일부 감량 검토
- `Ca:P` 보정
- 필요 시 `TDN` 보강
- 필요 시 조사료 대체 카드 제시
