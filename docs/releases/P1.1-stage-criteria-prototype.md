# P1.1 성장단계 기준 반영 프로토타입 릴리즈 노트

## 1. 이번 단계 이름

- `P1.1 성장단계 기준 반영`

## 2. 이번 단계 목적

- Xcode 시뮬레이터에서 직접 실행되는 iOS 프로토타입에 성장단계 기준을 명확히 반영한다.
- 사용자가 결과 화면에서 `왜 부족/적정/과잉인지`를 단계 기준과 함께 바로 이해할 수 있게 한다.

## 3. 포함 기능 목록

- `육성기 / 비육전기 / 비육후기` 단계별 기준 모델 추가
- 단계별 월령 범위 반영
- 단계별 `CP / TDN / Ca:P / NDF / ADF` 기준 반영
- 결과 화면에 `현재 단계 기준` 섹션 추가
- 결과 화면 순서 정리
  - 배합 요약
  - 현재 단계 기준
  - 판정 결과
  - AI 추천 1, 2, 3순위
- 비육후기 `NDF와 육질 간 트레이드오프` 안내 문구 추가
- Xcode 시뮬레이터 빌드 검증

## 4. 제외 기능 목록

- 실제 계산 엔진 연결
- 실제 원료 DB 연동
- 실제 AI 추천 로직
- 피그마 동기화

## 5. 우선 확인할 포인트

- 결과 화면에서 단계 기준이 한눈에 들어오는지
- `현재 단계 기준`이 `판정 결과`보다 먼저 나오는 흐름이 자연스러운지
- 비육후기 트레이드오프 설명이 과한지 아닌지
- 정보량이 너무 많은지, 오히려 충분하지 않은지

## 6. 다음 단계 후보

- 배합 입력값과 실제 계산 결과 연결
- 원료 DB 최소셋 연결
- 추천 로직 규칙 기반 구현
