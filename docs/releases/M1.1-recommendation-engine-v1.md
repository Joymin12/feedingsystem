# M1.1 추천안 엔진 1차 구현 릴리즈 노트

## 이번 단계 이름
- `M1.1 추천안 엔진 1차 구현`

## 이번 단계 목적
- 하드코딩된 추천 문구를 제거하고, 실제 배합 계산 결과를 바탕으로 `보유원료 우선안`, `가성비 우선안`, `균형 우선안`을 생성하는 결정론적 추천안 엔진으로 전환합니다.
- `AI 추천`이라는 표현을 제거하고, 실제 출시 앱 기준의 `추천안` 화면으로 정리합니다.

## 포함 기능
- `calculateMetrics(for:)`를 재사용하는 `simulateAdding()` 추가
- 원료 카테고리별 시험 추가량 기준으로 후보 원료 시뮬레이션
- `CP`, `TDN`, `NDF`, `ADF`, `Ca:P` 기준을 반영한 추천안 후보 평가
- 추천안 3전략 생성
  - `보유원료 우선안`
  - `가성비 우선안`
  - `균형 우선안`
- `현재 -> 적용 후 예상` 비교 표시
- `예상 비용 변화`, `장점`, `주의점`, `권장 보강량` 표시
- 모든 기준 적정 시 `현재 배합 유지 권장` 표시
- 실행 가능한 추가안이 없을 때 `배합 재설계 필요` 표시

## 제외 기능
- 기존 원료 감량/교체
- 실제 AI 설명 API 연동
- 서버 저장/동기화
- peNDF 제약 반영

## 우선 확인할 포인트
- 같은 입력에서 항상 같은 추천안이 나오는지
- `CP/TDN` 부족일 때 추천안이 실제로 바뀌는지
- `CP/TDN` 적정이고 `NDF/ADF/Ca:P`만 문제일 때 fallback이 자연스러운지
- `추천안` 화면 정보량이 과하지 않은지
