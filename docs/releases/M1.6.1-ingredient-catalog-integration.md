# M1.6.1 원료 카탈로그 실데이터 반영

## Summary

iOS 앱의 원료 mock 데이터를 114건 수집본 기반 실데이터 카탈로그로 교체했다.
추천 엔진 대상이 아닌 원료는 앱 DB 저장 대상에서 제외했고, 광물질은 일반 추천 후보가 아니라 보정용 보조군으로만 남겼다.
이후 소화 생리 저하 및 영양 불균형 우려가 있는 `커피피`, `커피부산물`도 저장 대상에서 추가 제외했다.

## Included

- 원료 카탈로그 파일 추가
  - `apps/ios/HanwooPrototype/HanwooPrototype/IngredientCatalog.swift`
- 저장 대상 원료 반영
  - `feed_no 1~93` 중 `21`, `50` 제외
  - `feed_no 109~114`
- 제외 원료 제거
  - `feed_no 94~108`
  - `feed_no 21`, `50`
- `moisture_pct = round(100 - dm_pct, 2)` 파생 반영
- `ash_pct` 필드 반영
- 기존 12종 mock 원료 배열 제거
- 샘플 배합을 실데이터 원료 ID(`FEED_x`) 기준으로 교체
- 교정 엔진 일반 후보군을 `selectionGroup == .tmr`로 제한

## Data Rules

- `tdn_pct > 100` 값은 허용
  - 예: 대두 `100.81`
- 광물질은 저장하되 일반 추천 후보에서는 제외
- `selectionGroup`
  - `tmr`: 일반 추천 후보
  - `mineral`: 추후 `Ca:P` 보정용

## Validation

- 제외 대상 ID가 카탈로그에 포함되지 않음
  - `94~108` 제거 확인
  - `21` 커피피 제거 확인
  - `50` 커피부산물 제거 확인
- `108` 산화아연 제외 확인
- `109~114` 광물질 유지 확인
- 시뮬레이터 빌드 성공
  - `xcodebuild -project apps/ios/HanwooPrototype/HanwooPrototype.xcodeproj -scheme HanwooPrototype -sdk iphonesimulator -destination 'generic/platform=iOS Simulator' build`

## Follow-ups

- `0.0` 값의 `실제 0 / 결측 의심` 구분 규칙 추가
- 실가격 데이터 추가
- `Ca:P` 보정 시 `mineral` 후보군 사용 로직 추가
