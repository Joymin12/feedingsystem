# P1.6 분석 화면 분리 프로토타입 릴리즈 노트

## 1. 이번 단계 이름

- `P1.6 분석 화면 분리`

## 2. 이번 단계 목적

- 배합 화면 상단의 중복 선택 UI를 제거한다.
- 분석 결과 화면의 세로 길이를 줄이고, `AI 추천`을 별도 화면으로 분리한다.
- 시뮬레이터에서 더 짧고 명확한 흐름으로 확인할 수 있게 만든다.

## 3. 포함 기능 목록

- `배합 선택` segmented UI 제거
- `배합 이름` 입력 카드를 배합 화면 상단으로 이동
- 분석 결과 화면에서 아래 항목 제거
  - `현재 단계 기준`
  - 상단 점프 버튼 4개
  - `다음: 판정 결과 보기`
  - `다음: AI 추천 보기`
  - 인라인 `AI 추천 1, 2, 3순위`
- 분석 결과 화면 흐름 정리
  - `성분 예상치`
  - `판정 결과`
  - `AI 추천 보기`
  - `사육일지 열기`
- 새 화면 추가
  - `AI 추천`

## 4. 제외 기능 목록

- 배합 다중 선택 UX 재설계
- 성장단계 기준 별도 상세 화면
- 추천 로직 고도화

## 5. 우선 확인할 포인트

- 배합 화면 상단이 더 단순해졌는지
- 분석 결과 화면이 덜 길고 덜 답답한지
- `AI 추천`을 새 화면으로 넘기는 방식이 더 자연스러운지
- `현재 단계 기준`을 제거해도 결과 해석에 큰 불편이 없는지

## 6. 다음 단계 후보

- 결과 화면에서 성장단계 기준을 접힘 도움말로 최소 노출
- 배합 전환 방식 재설계
- AI 추천 화면에 조정 전후 예상 변화 추가
