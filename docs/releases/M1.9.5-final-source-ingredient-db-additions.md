# M1.9.5 최종 원료 원본 DB 추가분 고정

## Summary

`feed_no 115~130` 구간 중 최종 포함 가능한 원료를 실제 워크스페이스 파일로 고정했다.
이번 단계는 API seed처럼 완전한 영양 스냅샷 스키마가 아니라, `null` 결측을 그대로 보존하는 최종 원료 원본 DB를 만드는 작업이다.

## Added File

- `/Users/jowm/Desktop/feedingsystem/docs/seeds/ingredients.source.extensions.final.json`

## Applied Rules

- `119 커피박` 제외
- `21 커피피`, `50 커피부산물`, `94`, `95~108`, `119` 제외 정책 유지
- `118 맥강`, `122 주정박`, `125 비지`, `126 미강`, `128 루핀`, `130 감귤박`은 기존 원료와 중복 제거하지 않고 독립 원료로 유지
- `db_matched` 자동 매칭 제거
  - `맥강`, `주정박`, `비지`, `미강`, `루핀`, `감귤박`은 기존 원료와 연결하지 않고 독립 원료로 유지
- 결측 영양성분은 `0`으로 치환하지 않고 `null` 유지
- 카테고리 정규화
  - `116 야자박 -> 농산부산물`
  - `118 맥강 -> 농산부산물`
  - `120 채종박 -> 농산부산물`
  - `121 참깻묵(호마박) -> 농산부산물`
  - `123 소맥피(밀기울) -> 농산부산물`
  - `126 미강 -> 농산부산물`
  - `127 면실박 -> 농산부산물`
  - `128 루핀 -> 농산부산물`
  - `129 대두박 -> 농산부산물`

## Important Note

이 파일은 앱/API에서 바로 읽는 `ingredients.seed.json`을 대체하지 않는다.
현재 API seed는 완전한 영양 스냅샷을 요구하므로, `null`이 포함된 원본 DB는 별도 source DB로 관리한다.
