# P1 iOS 설치형 프로토타입 릴리즈 노트

## 1. 이번 단계 이름

- `P1 iOS 설치형 프로토타입`

## 2. 이번 단계 목적

- Xcode에서 열어 iOS Simulator와 실제 아이폰에 설치 가능한 앱 프로토타입을 만든다.
- 사용자가 네이티브 화면 흐름으로 직접 입력과 이동을 체험한다.

## 3. 포함 기능 목록

- SwiftUI 기반 iOS 앱 프로젝트 추가
- 로그인 / 회원가입 더미 흐름
- 사육 단계 선택
- 하단 탭 5개
  - 홈
  - 배합
  - 최근 분석
  - 커뮤니티
  - 내 농장
- 배합 입력 더미 편집
- 분석 결과 더미 표시
- AI 추천 1, 2, 3순위 더미 표시
- 최근 분석 목록
- 사육일지 목록
- `기록 추가 -> 배합비 선택 -> 글쓰기 -> 기록 저장`
- `기록 상세 -> 기록 수정`
- Xcode 시뮬레이터 빌드 검증 완료

## 4. 제외 기능 목록

- 실제 API 연동
- 실제 영양 계산
- 실제 AI 추천 호출
- 서버 저장 / 계정 연동
- 커뮤니티 상세 / 글쓰기
- 파일 내보내기, PDF, 엑셀

## 5. 우선 확인할 포인트

- 로그인과 단계 선택 진입 흐름이 자연스러운지
- 배합 탭에서 배합비 편집과 분석 결과 진입이 쉬운지
- 분석 결과의 정보량이 과한지 부족한지
- 사육일지의 `추가`보다 `수정` 중심 느낌이 잘 드는지
- 내 농장에서 최근 분석과 사육일지로 다시 들어가는 구조가 자연스러운지
