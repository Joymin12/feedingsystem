# P1.2 로컬 계산 연결 프로토타입 릴리즈 노트

## 1. 이번 단계 이름

- `P1.2 로컬 계산 연결`

## 2. 이번 단계 목적

- iOS 프로토타입에서 배합 입력값을 바꾸면 결과 화면 수치가 실제로 다시 계산되게 만든다.
- 최소 원료 영양 DB를 앱 내부에 두고 `원물 -> DM -> %DM` 계산 흐름을 시뮬레이터에서 바로 검증할 수 있게 한다.

## 3. 포함 기능 목록

- 앱 내부 최소 원료 영양 DB 추가
- `kg / g` 입력을 `원물 kg`로 환산
- `DM_kg`, `CP`, `TDN`, `NDF`, `ADF`, `NFC`, `EE`, `Ca`, `P`, `Ca:P` 실제 계산 반영
- 입력값 변경 시 결과 화면 수치 재계산
- 단계 기준 기반 판정 결과 동적 반영
- 수분 조건을 반영한 추천 문구 보정
- 알 수 없는 원료는 계산에서 제외하고 결과 요약에 안내
- Xcode 시뮬레이터 빌드 검증

## 4. 제외 기능 목록

- 실제 서버/API 연동
- OpenAPI 기반 원료 DB 연동
- 실제 추천 엔진 고도화
- 계산 결과 영구 저장

## 5. 우선 확인할 포인트

- 배합량을 바꾸면 결과 화면 수치가 실제로 변하는지
- `수분`, `CP`, `TDN`, `Ca:P` 변화가 직관적인지
- 알 수 없는 원료를 직접 추가했을 때 요약 문구가 이해되는지
- 추천 문구가 수분 조건과 충돌하지 않는지

## 6. 다음 단계 후보

- OpenAPI/실제 원료 DB 최소셋 연결
- 추천 규칙 세분화
- 계산 결과를 최근 분석에 스냅샷 저장
