# 한우 TMR/TMF 배합관리 및 교정 추천 앱 제안서·수행계획서

## 1. 프로젝트 개요

### 1.1 프로젝트명

한우 TMR/TMF 배합관리 및 교정 추천 모바일 앱 개발

### 1.2 추진 배경

한우 산업에서 사료비는 전체 생산비의 약 40~45%를 차지하는 핵심 비용 요소이며, 어떤 사료를 어떤 비율로 성장단계에 맞추어 급여하느냐는 생산성과 직결된다. 특히 최근에는 균일한 영양 공급과 생산성 향상을 위해 TMR(Total Mixed Ration) 및 TMF(Total Mixed Fermentation) 급여 방식이 확대되고 있으며, 정부와 축산 관련 기관 역시 체계적인 배합 및 사양관리를 지속적으로 권장하고 있다.

그러나 실제 현장에서는 배합 설계와 교정 과정이 여전히 경험과 수작업에 크게 의존하고 있다. 많은 농가가 엑셀, 수기 기록, 주변 농가 사례, 외부 컨설팅 자료 등을 참고하여 배합비를 구성하고 있으며, 신규 농가나 초보 사육자의 경우 배합 설계 자체에 높은 진입장벽을 느끼는 경우가 많다. 또한 컨설팅 비용 부담, 원료 수급의 불안정성, 지역별 사용 원료 차이 등으로 인해 다른 농가의 배합비를 그대로 적용하기 어려운 한계도 존재한다.

여기에 축산업 종사자의 고령화가 지속되면서 디지털 기반 배합관리 시스템 활용에도 현실적인 어려움이 나타나고 있다. 현장에서는 모바일 기반으로 쉽고 직관적으로 사용할 수 있는 관리 도구에 대한 수요가 높아지고 있으나, 실제로는 농가의 작업 흐름과 원료 운용 방식을 충분히 반영한 배합관리 앱이나 교정 추천 시스템은 아직 부족한 실정이다.

배합비의 불균형은 단순한 계산 오류를 넘어 한우의 건강 상태와 성장 효율에 직접적인 영향을 미친다. 조단백질(CP), 가소화영양소총량(TDN), 조지방(EE), 섬유소(NDF/ADF), 칼슘(Ca), 인(P) 등의 균형이 맞지 않을 경우 사료 효율 저하, 성장 지연, 건강 문제 등이 발생할 수 있다. 특히 실제 현장에서는 여러 영양소를 동시에 고려하여 배합을 교정해야 하므로, 경험만으로 일관된 최적 배합을 유지하기 어렵다.

본 프로젝트는 이러한 문제를 해결하기 위해, 농가가 실제 사용하는 원료와 원물 기준 kg 입력 방식에 맞춘 한우 TMR/TMF 배합관리 앱 구축을 목표로 한다. 사용자는 현재 배합비를 입력하여 예상 영양상태를 즉시 분석할 수 있으며, 앱은 복합 영양상태를 기반으로 현실적인 교정 추천안을 제시하여 배합 수정 방향을 안내한다. 또한 사용자의 원료 사용 범위와 현장 조건을 함께 반영함으로써, 농가의 접근성을 높이고 배합 안정성, 사료 효율, 사양관리의 일관성을 향상시키고자 한다.

### 1.3 프로젝트 목표

본 프로젝트의 목표는 한우 농가가 복잡한 배합 설계와 교정 작업을 보다 쉽고 정확하게 수행할 수 있도록, 현장 친화적인 모바일 기반 배합관리 시스템을 구축하는 데 있다. 특히 사료비 비중이 높은 한우 산업의 특성을 고려하여, 단순 기록 기능을 넘어 영양 분석과 교정 추천, 원료 관리, 운영 기록까지 하나의 흐름으로 연결하는 것을 목표로 한다.

세부 목표는 다음과 같다.

- 한우 성장단계별 기준에 따라 배합의 영양 상태를 신속하게 분석할 수 있는 모바일 배합관리 환경 구축
- 원물 기준 kg 입력을 기반으로 DM 기준 영양 계산을 자동 수행하여 농가의 계산 부담과 오류 가능성 축소
- `CP`, `TDN`, `EE`, `NDF`, `ADF`, `Ca`, `P`, `Ca:P`, 수분 등을 동시에 고려한 복합교정 추천 기능 구현
- 농가별 원료 사용 범위와 현장 조건을 반영한 현실적 배합 수정 지원
- 신규 농가와 고령 농가도 활용할 수 있는 직관적이고 접근성 높은 사용자 경험 제공
- 사육일지, 최근 분석, 배합 저장, 커뮤니티 기능을 포함한 통합형 사양관리 앱 완성

### 1.4 최종 구현 목표

최종 출시 앱은 한우 농가가 현장에서 직접 활용할 수 있는 실사용 중심의 배합관리 솔루션을 목표로 한다. 사용자는 자신의 원료 체계와 사육단계에 맞추어 배합비를 입력하고, 앱은 해당 배합의 영양 상태를 즉시 분석한 뒤, 여러 영양소를 동시에 고려한 교정안을 제시하여 실제 급여 조정까지 연결할 수 있어야 한다. 또한 단순 분석 결과 제공에 그치지 않고, 왜 이러한 교정이 필요한지를 이해할 수 있는 설명 구조를 함께 제공하는 것을 지향한다.

최종 구현 목표는 다음과 같다.

- 농가가 원물 기준 kg 단위로 쉽고 빠르게 배합비를 입력할 수 있는 직관적 입력 인터페이스 구현
- 한우 성장단계별 요구량에 맞추어 배합의 영양 상태를 자동 판정하는 표준화된 분석 엔진 구현
- 복수의 영양소 충돌 상황에서도 전체 균형을 고려하여 교정안을 제시하는 복합교정 추천 엔진 구현
- 사용자별 원료 선택, 배합 저장, 최근 분석 기록, 사육일지 관리 기능을 포함한 운영형 서비스 흐름 완성
- 커뮤니티 기능을 통한 현장 사례 공유 및 정보 교류 기반 마련
- 고령 농가와 신규 농가도 활용 가능한 모바일 중심 UX 구현
- 향후 데이터 축적, 설명형 추천, 비용 분석 고도화로 확장 가능한 구조 확보

## 2. 서론

### 2.1 문제 인식

한우 사양관리에서 배합비는 단순한 원료 조합이 아니라 생산성과 직결되는 경영 변수이다. 사육 단계에 따라 요구되는 단백질, 에너지, 섬유, 광물질 수준이 다르고, 원료 특성도 고정되어 있지 않다. 같은 명칭의 원료라도 출처와 가공 방식에 따라 성분 차이가 발생할 수 있으며, 현장에서는 이러한 차이를 충분히 반영하기 어렵다.

기존 방식은 다음과 같은 한계를 가진다.

- 배합 기록이 수기로 분산되어 관리된다.
- 계산이 엑셀이나 경험에 의존해 재현성이 낮다.
- 한 성분을 맞추면 다른 성분이 틀어지는 다중 충돌 문제가 자주 발생한다.
- 교정 과정에서 왜 이렇게 바꾸는지에 대한 설명이 부족하다.
- 농가별 실제 사용 원료 범위가 다른데도 이를 반영하지 못하는 경우가 많다.

이 문제는 단순 기록 앱으로는 해결되지 않는다. 분석, 교정, 설명, 원료 관리, 저장 기능이 하나의 흐름으로 연결된 현장형 운영 솔루션이 필요하다.

### 2.2 해결 방향

본 프로젝트는 `배합 입력 → 영양 분석 → 복합교정안 추천 → 저장 및 재활용`의 흐름을 하나의 모바일 앱으로 통합한다. 특히 추천 엔진은 단순히 부족한 성분을 채우는 방식이 아니라, 현재 배합에서 어떤 원료를 줄이고 어떤 원료를 늘려야 전체 영양상태가 적정에 가까워지는지를 계산하도록 설계한다.

또한 사용자가 직접 배합을 입력하는 현실을 고려하여 입력 단위는 원물 kg를 유지하고, 내부 계산은 DM 기준으로 수행한다. 이는 농가 사용성을 해치지 않으면서도 분석 정확도를 확보하기 위한 구조이다.

## 3. 본론

### 3.1 시스템 구성

본 시스템은 최종적으로 네 영역으로 구성된다.

#### 3.1.1 원료 DB 및 원료 관리 체계

원료 DB는 곡류, 유박류, 조사료, 농산부산물, 광물질 등으로 분류되며, 표준 원료와 현장 원료를 함께 운용한다. 현장 원료는 자동 병합을 최소화하여 실제 농가가 사용하는 명칭과 성분 차이를 반영할 수 있도록 한다.

핵심 운영 원칙은 다음과 같다.

- 원료 원본 데이터는 별도 source DB로 보존
- 앱 계산용 카탈로그는 즉시 사용 가능한 구조로 유지
- 현장명 원료와 표준 원료를 목적에 따라 구분 운영
- 사용자별 사용하는 원료를 선택하고 저장할 수 있도록 설계

이를 통해 농가는 자신이 실제 사용하는 원료 중심으로 배합을 설계할 수 있으며, 입력 효율과 추천 현실성을 함께 확보할 수 있다.

#### 3.1.2 배합 계산 및 분석 엔진

배합 계산 엔진은 사용자가 입력한 원물 kg를 기준으로 각 원료의 DM량을 계산한 뒤, 전체 배합의 CP, TDN, EE, NDF, ADF, Ca, P, Ca:P, 수분 등을 산출한다. 이후 성장단계별 기준과 비교하여 각 항목을 `부족 / 주의 / 적정 / 과잉`으로 판정한다.

이 구조는 다음 장점을 가진다.

- 농가의 실제 입력 습관을 유지할 수 있다.
- 내부 계산은 표준화되어 재현성이 높다.
- 분석 결과를 반복적으로 저장하고 비교할 수 있다.
- 향후 서버 연동, 리포트, 비용 분석 기능으로 확장하기 쉽다.

#### 3.1.3 복합교정 추천 엔진

추천 엔진은 본 프로젝트의 핵심 기능이다. 단일 영양소만 맞추는 방식이 아니라, 현재 배합의 여러 문제를 동시에 고려하여 복합교정안을 생성한다.

예를 들면 다음과 같은 방식으로 동작한다.

- `CP 과잉`이면 단백질 기여도가 높은 원료를 우선 감량
- 감량 후 `TDN`이 부족해지면 에너지원 보강
- `EE 과잉`이면 고지방 원료를 감량하고 CP를 유지할 수 있는 원료를 탐색
- `Ca 부족 + P 과잉`이면 고인(P) 원료를 줄이고 광물질 원료로 보정
- `NDF/ADF 부족`이면 조사료 계열 보강

즉 교정 엔진은 한 항목만 맞추는 계산기가 아니라, 전체 배합을 반복적으로 시뮬레이션하면서 최종적으로 적정 상태에 가까운 조합을 찾는 구조로 설계된다.

#### 3.1.4 사용자 운영 기능

앱은 단순 분석도구가 아니라 운영형 앱으로 설계된다. 따라서 다음 기능을 포함한다.

- 회원가입 및 로그인
- 사용자별 원료 선택
- 배합 저장 및 수정
- 최근 분석 기록 관리
- 사육일지 작성 및 조회
- 커뮤니티 글 작성 및 삭제

사용자는 회원가입 시 자신이 사용하는 원료를 선택할 수 있으며, 이후 배합 입력 시 원료 추가 화면에서 자신의 원료만 중심적으로 확인할 수 있다. 이는 현장 입력 속도를 높이고 불필요한 탐색 비용을 줄이는 기능이다.

### 3.2 수행 계획

본 프로젝트는 다음 단계로 수행한다.

#### 1단계: 데이터 및 기준 정리

- 영양 분석 및 상태 판정 로직 개발

#### 3단계: 복합교정 추천 엔진 개발

#### 5단계: 검토 및 출시 준비

- 대표 배합 케이스 점검

- 설명 문구 정리 및 문서화
- 내부 시연 및 배포 준비

### 3.3 기술적 차별성

본 프로젝트는 단순한 축산 정보 앱과 다음 점에서 차별화된다.

첫째, 원물 입력과 DM 계산을 분리하여 현장성과 정확성을 동시에 확보한다.

둘째, 추천안을 단일 원료가 아닌 복합교정안 형태로 제시한다. 이는 실제 배합 교정 방식에 더 가깝고, 한 항목을 맞추다 다른 항목이 무너지는 문제를 줄일 수 있다.

셋째, 농가별 원료 사용 범위를 반영한다. 모든 원료를 일괄 추천하는 것이 아니라, 사용자가 선택한 현실적 원료 범위 안에서 교정안을 제시할 수 있다.

넷째, 향후 데이터 기반 고도화 여지가 크다. 현재는 계산 및 시뮬레이션 중심 구조로 설계하되, 이후에는 비용 분석, 추천 설명 고도화, 사양 성적 연계 등으로 확장 가능하다.

## 4. 기대 효과 및 수익성

### 4.1 기대 효과

본 프로젝트가 실제 운영되면 다음과 같은 효과를 기대할 수 있다.

- 농가의 배합 검토 시간 단축
- 영양 불균형 조기 발견
- 동일 농장 내 배합 기록 표준화
- 사육단계별 급여 정확도 향상
- 경험 의존도가 높은 배합 조정 업무의 체계화
- 모바일 기반 현장 대응력 향상
- 커뮤니티 기반 정보 공유 확대

특히 왜 이러한 교정이 필요한지 설명 가능한 구조를 제공하면, 단순 계산 앱이 아니라 의사결정 지원 도구로서의 신뢰도를 확보할 수 있다.

### 4.2 시장성과 사업성

한우 농가, TMR 제조업체, 사료 컨설턴트, 농축협 현장지도 조직은 모두 배합 데이터와 교정 기준을 필요로 한다. 본 프로젝트는 초기에는 농가 직접 사용형 앱으로 진입하되, 이후 다음과 같은 형태로 확장할 수 있다.

- 농가용 구독형 서비스
- TMR 업체 전용 배합 관리 도구
- 컨설턴트용 다농가 관리 버전
- 농축협·지자체 보급형 현장 지원 앱

### 4.3 예상 수익 모델

수익모델은 다음과 같이 설계할 수 있다.

#### 1. 구독형 모델

- 기본 배합 입력 및 분석 기능 무료 제공
- 고급 추천안, 이력 비교, 리포트 기능 유료화
- 월 구독 또는 연 구독 모델 적용

#### 2. B2B 공급 모델

- 사료회사, TMR 업체, 컨설팅 조직에 SaaS 형태 제공
- 조직별 원료 DB, 가격표, 사용자 관리 기능 확장

#### 3. 데이터 기반 부가 서비스

- 배합 패턴 분석 리포트
- 성장단계별 급여 비교 리포트
- 장기적으로 실제 사양 성적과 연계한 추천 고도화 서비스

#### 4. 교육 및 컨설팅 연계

- 배합 교육 자료와 연동
- 농가 현장 컨설팅 패키지화

### 4.4 수익성 전망

본 프로젝트는 초기에는 구축 및 현장 적용 비용이 필요하지만, 기준 엔진과 원료 DB, 사용자 흐름이 정착되면 사용자 수 증가에 따른 단위 운영비는 상대적으로 낮아진다. 또한 축산 현장은 한번 사용 습관이 형성되면 전환 비용이 높은 편이므로, 사용성이 안정되면 장기 구독 전환 가능성이 높다.

따라서 본 프로젝트는 단기 대규모 수익을 목표로 하기보다, 현장 문제를 정확히 해결하는 제품을 기반으로 중장기 반복 매출 구조를 만드는 방향이 적합하다.

## 5. 결론

본 프로젝트는 한우 배합관리의 핵심 문제인 `배합 입력의 비표준성`, `영양 계산의 복잡성`, `교정안 도출의 난이도`, `기록 관리의 분산성`을 하나의 iOS 앱으로 통합 해결하려는 사업이다.

최종 출시 앱은 배합 분석, 복합교정 추천, 사용자별 원료 운영, 사육일지, 커뮤니티 기능을 하나의 서비스 흐름으로 연결하여, 농가가 실제 사양관리 의사결정을 모바일에서 수행할 수 있도록 하는 것을 목표로 한다.

즉 본 사업은 단순한 계산 도구가 아니라, 축산 현장의 의사결정 체계를 디지털화하는 운영형 솔루션으로 정의할 수 있다. 향후에는 추천 엔진 고도화, 비용 분석, 사용자 데이터 축적, B2B 공급 모델 확대 등을 통해 보다 높은 사업적 가치로 확장할 수 있다.

결론적으로 본 프로젝트는 한우 농가의 실제 문제를 해결할 수 있는 실행 가능성이 높은 서비스이며, 축산 디지털 전환과 데이터 기반 사양관리 고도화에 기여할 수 있는 사업이다.
