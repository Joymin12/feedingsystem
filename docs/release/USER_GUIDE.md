# 사용자 가이드 (USER_GUIDE)

Hanufit은 한우 TMR/TMF 배합을 분석하고, 성장단계 기준에 맞춘 교정 배합비를
제안하는 앱입니다. 모든 계산은 휴대폰 안에서 수행되며 데이터가 외부로
전송되지 않습니다.

## 시작하기

1. 회원가입 후 농장의 성장단계(육성기/비육전기/비육후기)를 선택합니다.
2. 홈에서 "배합하기"를 누릅니다.

## 배합 입력

- 배합 이름과 성장단계를 정하고 "원료 추가"로 원료를 고릅니다.
- 원료별 투입량(kg/g)과 단가(원/kg)를 입력하면 총 원료비가 실시간 계산됩니다.
- **내 원료 직접 추가**: 사료회사 성적서의 성분(수분, CP, TDN, EE, NDF, ADF,
  NFC, 회분, Ca, P)을 직접 입력하면, 이후 계산과 추천에 그 값이 우선
  사용됩니다. `내 농장 > 내 원료 관리`에서 언제든 수정·삭제할 수 있습니다.

## 분석 결과 읽기

- 상단 카드: 수분·CP·TDN 요약.
- 원물 투입 현황: 원료별 원물량과 건물 환산량.
- 판정 결과: 축마다 `부족 / 주의 / 적정 / 과잉` 라벨과 현재값·기준 범위,
  설명이 표시됩니다. 라벨은 색과 함께 텍스트로도 표기됩니다.

## 증감 시뮬레이션과 추천

"추천안 보기"를 누르면 앱의 최적화 엔진이 **배합에 이미 들어 있는 원료만**
증감해 기준에 최대한 가까운 조합을 찾습니다.

- 추천안은 원료별 증감 kg(원물 기준)으로 표시되며, 적용 후 총량은 입력한
  총량과 같습니다.
- 전후 비교에서 각 영양소의 현재값 → 예상값과 판정 변화를 확인할 수 있습니다.
- 조정안에는 적용 시 **총 원료비 변화**(현재 → 적용 후, 증감액)도 함께
  표시됩니다. 단가를 입력하지 않은 원료는 기본단가로 계산합니다.
- 기준을 모두 만족하는 조합이 불가능하면 앱은 결과를 지어내지 않고 이유를
  알려줍니다. 예: "배합 내 원료만으로는 칼슘(Ca)을 기준까지 올리기 어렵습니다.
  석회석 같은 칼슘원 추가를 검토해보세요." 이때 가장 가까운 참고안이 함께
  표시됩니다.

> 추천은 의사결정 보조 정보입니다. 실제 급여 변경 전에 사양 전문가와
> 상의하세요.

## 이력·내보내기

- 분석을 저장하면 `최근 분석`에서 언제든 다시 볼 수 있습니다. 저장 시점의
  배합과 엔진 버전이 함께 기록되어 나중에 봐도 같은 값이 표시됩니다.
- 결과는 CSV/PDF로 내보내거나 인쇄할 수 있습니다.

## 자주 묻는 질문

- **원료 DB 값과 우리 원료가 달라요** — 카탈로그 값은 표준 성분표 기반
  참고값입니다. `내 원료 직접 추가`로 실제 성적서 값을 입력하면 그 값이
  우선 적용됩니다.
- **"성분표가 없어 계산에서 제외했습니다"는 무슨 뜻인가요** — 물처럼 성분이
  등록되지 않은 라인은 총량과 수분에만 반영되고 영양소 계산에서 빠집니다.
- **같은 배합인데 결과가 왜 항상 같나요** — 엔진이 결정론적이기 때문입니다.
  같은 입력에는 항상 같은 추천이 나오도록 설계되어 있습니다.
