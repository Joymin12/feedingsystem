# iOS App

## Goal

- Provide a SwiftUI iOS app that can be opened in Xcode and installed on an iPhone.
- Current focus: local calculation/recommendation flow, usability validation, and release-oriented refactor.

## Run

1. Open `HanwooPrototype.xcodeproj` in Xcode.
2. Select your Apple ID Team in `Signing & Capabilities`.
3. Choose an `iPhone` or `iOS Simulator` target.
4. Press `Run`.

## Current Scope

- Login.
- Sign-up.
- Growth-stage selection.
- Home.
- Formula entry.
- Nutrition analysis.
- Primary recommendation.
- Recent analysis.
- Diary.
- Community.
- My Farm.
- User-entered ingredient add/edit/delete.

## Out Of Scope For The Current Release Path

- Required live API integration.
- Required live AI API call.
- Required server persistence.
- Push notifications.
- TestFlight metadata.
- File export.
